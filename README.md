# Research Writing

An agent skill for writing and editing technical texts in Russian. It covers documentation, test reports, technical reviews, instructions, and academic papers.

Use it to plan a document around the reader's task, connect explanations to evidence, verify figures and citations, or edit an existing draft in the author's style. The examples illustrate methods that transfer across technical fields.

Install the skill by copying this repository to your agent's skills directory as `research-writing`. Start with [SKILL.md](SKILL.md).
