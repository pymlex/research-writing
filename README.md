# Research Writing

An agent skill for writing and editing technical texts in Russian. It covers documentation, test reports, technical reviews, instructions, and academic papers.

Use it to plan a document around the reader's task, connect explanations to evidence, verify figures and citations, or edit an existing draft in the author's style. It also covers applicable GOST standards, Word layout checks, and a Russian-language style pass with ``humanizer-ru`` when available.

Install the skill by copying this repository to your agent's skills directory as `research-writing`. Start with [SKILL.md](SKILL.md).
